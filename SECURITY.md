# Security

## Reporting a vulnerability

Report privately through [GitHub's advisory form](https://github.com/DavidZapataOh/STRICKLE/security/advisories/new). Please do not open a public issue for a security problem.

Include what you did, what happened, and what you expected. A proof of concept helps.

This project is in early development: the certification circuit is not written yet, and nothing is deployed to a public network. The threat model and a full disclosure policy will be published with the first certification release.

## Scope

This repository. The local development network it starts with Docker runs with development keys and is not a target.
